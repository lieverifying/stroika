**Бренд сменён:** Prime Studio Residence → **ВИМІР**. Где в `docs/TZ.md` написано «Prime Studio», использовать «Вимір». При расхождении ТЗ и этого файла прав этот файл.

## Что строим
Сайт кухонь и корпусной мебели на заказ: Черкаси та область. Ремонта на сайте нет (решение владельца 2026-10-20).
Единственная цель сайта — заявка на бесплатный замер (квиз или форма) или клик по телефону / Viber / Telegram.
Всё, что не ведёт к заявке, не делаем.

## Жёсткие правила
1. **Одна фаза за раз.** Работаем только над текущей фазой из `docs/PHASES.md`. Не переписываем то, что уже принято.
2. **Не выдумывать факты.** Цены, сроки, гарантия, число объектов, отзывы, имена мастеров, материалы — только заглушки вида `{{PRICE_PER_METER}}`, `{{WARRANTY_YEARS}}`. Все заглушки собраны в `src/content/facts.ts`.
3. **Запрещённые слова:** «масив» / «массив» (пока владелец не подтвердит), «шпон», «менеджер», «свій дизайнер», «ремонт», «під ключ», «субпідрядники». Про дизайн — только «дизайн-проєкт». Проверка — `scripts/check-words.mjs` в `npm run build`.
4. **Никаких стоковых фото.** Исключение — визуализации этапов на «Як ми створюємо» (`src/assets/stories/`), всегда с подписью «Візуалізація етапів». Остальное — только свои фото из `src/assets/photos/` (сборка Astro сама делает WebP/AVIF и адаптивные размеры); видео — `public/photos/video/`. Пока их нет — серые плейсхолдеры с подписью размера.
5. **Язык сайта — украинский.** Документация и комментарии — русский.
6. **Мобильный первым:** сначала 375 px, затем 768 и 1280. Ничего не уезжает вбок.
7. После каждой завершённой задачи — коммит с понятным сообщением на русском и `git push`.

## Стек (по умолчанию, архитектор может предложить замену с обоснованием)
- Astro + Tailwind CSS, статическая сборка (папка `dist/`), без серверного рендеринга. Подробности — `docs/ARCHITECTURE.md`.
- Кейсы портфолио — Astro Content Collections: Markdown-файлы в `src/content/cases/`, без админки.
- Хостинг: виртуальный хостинг владельца в панели adm.tools (Хостинг Україна): статика + PHP 8.1+, SSH/SFTP, бесплатный SSL. Serverless-функций нет.
- Заявки (квиз, форма замера, «Нестандартне завдання» с файлами) → PHP-скрипт `api/lead.php` на хостинге → Telegram Bot API + Google Sheets (через веб-приложение Google Apps Script) + email. Если один канал упал, заявка уходит по остальным. В сообщении в Telegram **первая строка — способ связи** (Viber / Telegram / Дзвінок); формы уже кладут `contactMethod` первым полем. Токены и ключи — в конфиге вне публичной папки, в репозиторий не попадают. Защита — поле-ловушка и ограничение частоты по IP, без капчи. **Бэкенд форм — не раньше фазы 6.**
- Деплой (фаза 9): GitHub Actions — при push в main собрать сайт и загрузить `dist/` и `api/` на хостинг по SFTP. Доступы только в GitHub Secrets, владелец вносит их сам.
- Домен: **не зарегистрирован** (кандидаты vymir.ua / vymir.com.ua) — в коде через переменную `SITE_URL`. prime-studio.space позже перенаправить на новый домен.
- Тесты: Playwright (e2e на 375 и 1280 px), Lighthouse.

## Бренд и дизайн
- Название: **ВИМІР**. Дескриптор: «Кухні та меблі · Черкаси». Слоган-направление: «кухні та меблі по вашому розміру».
- Логотип: вариант «Кутник» (жёлтый столярный угольник + буква В + слово ВИМІР). Знак «угольник + В» — для favicon и аватарок.
  Файлы: `public/brand/logo.svg`, `public/brand/logo-dark.svg`, `public/brand/mark.svg`. **Текст в SVG должен быть переведён в кривые** — живой `<text>` со шрифтом не использовать.
  Пока финальных файлов нет — временный SVG, помеченный TODO.
- Цвета (`src/styles/tokens.css`):
  - Графит `#1E2124` — текст, тёмные фоны.
  - Рулетка `#E3B12C` — **только** кнопки заявки и акценты, максимум один жёлтый элемент на экран. Текст на жёлтом — графитовый, не белый.
    Исключение: жёлтый угольник в логотипе и favicon — это не кнопка и не акцент, в правило «один жёлтый на экран» не входит.
  - Штукатурка `#F1F1EE` — основной фон; белый `#FFFFFF` — карточки.
  - Дуб `#8A5A33` — редко, для тепла.
- Шрифты (self-host через `@fontsource`, подмножества cyrillic + latin, кириллица с і, ї, є, ґ): заголовки H1–H3 — Unbounded 500 (600 не используем); текст — Manrope 400–600; размеры и цены — JetBrains Mono.
- Цены пишем «грн», символ ₴ не используем.
- Голос: точно, спокойно, по-свойски. Цифры вместо прилагательных, без «найкращих» и восклицательных знаков, мастера по именам (имена — только реальные, до получения — заглушки).
- Стиль: спокойный и дорогой, много воздуха, крупные фото, минимум текста в блоке. Мотив замера (размерные линии, мм) — как деталь, не как декор на каждом блоке.
- Кнопки ≥ 48 px по высоте, текст на телефоне ≥ 16 px, контраст WCAG AA.
- На телефоне всегда видна нижняя панель: «Подзвонити» / «Viber» / «Розрахувати». Она не перекрывает формы.
- Не запрещать масштабирование страницы (никаких `user-scalable=no`).

## Решения владельца (сводное обновление, 2026-10-20)
Работаем с текущим сайтом и структурой, варианты дизайна отменены.

**Что делаем и как**
- Только корпусні меблі: кухні, шафи, гардеробні, передпокої, дитячі, тумби у ванну, ТВ-зони, меблі для бізнесу (`facts.services.furniture`). Объекты: квартири, будинки, офіси, магазини, салони (`facts.services.objects`). Рестораны, кафе, мягкую мебель не упоминаем.
- Ремонт убран полностью: страница, ветка квиза, «під ключ», демонтаж, электрика, сантехника, плитка — нигде, включая FAQ, футер и мета-описания.
- Детали изготавливают фабрики-партнёры. «Без субпідрядників» и «бригада» не используем. Замір, дизайн-проєкт і монтаж — своя команда.
- Сроки: кухня 2–3 місяці від авансу, шафи та інші меблі 1–2 місяці від авансу (`facts.terms`). Срочное изготовление не обещаем.
- Монтаж включает: врізка мийки та варильної поверхні, вбудована техніка, підключення води та розеток, прибирання (`facts.services.install`).
- Зона — «Черкаси та область».

**Блок 6**
- Заголовок «Своя команда», подзаголовок «Замір, дизайн-проєкт і монтаж — наша команда.»
- Без имён и личных фото мастеров: одно фото команды или монтажа (`facts.teamPhoto`) и текст. Карточки мастеров — за флагом `facts.flags.teamCards` (выключен).

**Квиз и цена**
- Шаг 1: Кухня / Шафа або гардеробна / Інші меблі / Інше, нестандартне. «Інше, нестандартне» ведёт в блок #zapyt.
- Сезонный бейдж выключен (`flags.seasonalBadge = false`). В шаге сроков — «Протягом 3 місяців» вместо «до Нового року».
- Экран А (автоматическая цена) выключен (`flags.quizResultVariant = 'B'`), код не удаляем.
- Над квизом: «Оберіть, яку кухню хочете, — ми порахуємо і надішлемо ціну у зручний для вас месенджер».
