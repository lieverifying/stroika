# План работ по фазам

Правило: следующая фаза начинается, только когда у текущей выполнен критерий готовности.
Агенты ECC вызываются фразой «используй агента <имя>» или командами `/everything-claude-code:<команда>`.
Список установленных агентов — команда `/agents` в Claude Code.

## СЕГОДНЯ: макет и дизайн (фазы 0–4, без реальных данных)

### Фаза 0 — Подготовка репозитория
- В корне `CLAUDE.md`, в `docs/` — `PHASES.md` и `TZ.md`.
- **Готово, когда:** файлы в репозитории, первый коммит запушен.

### Фаза 1 — Архитектура
- **Агенты:** `architect`, затем `planner`.
- Результат: `docs/ARCHITECTURE.md` и `docs/PLAN.md`. Код не пишется.
- **Готово, когда:** владелец прочитал оба файла и подтвердил.

### Фаза 2 — Дизайн-система
- Astro + Tailwind; `tokens.css`, шрифты, базовый шаблон страницы; компоненты Header с бургером, Button, MobileBottomBar — и сразу блок 1 (первый экран главной) на 375 и 1280 px. Цель — не больше 8 часов.
- **Готово, когда:** первый экран главной открывается в браузере, скриншоты 375 и 1280 px в `docs/screens/`, владелец одобрил.

### Фаза 3 — Главная страница на заглушках
- Остальные блоки из ТЗ, сначала 375 px, потом 1280 px. Одна задача = один-два блока, после каждой скриншоты и коммит. Компоненты (SectionTitle, CaseCard, поля форм и т. д.) создаются вместе с блоками, которым они нужны. В конце фазы — страница `/styleguide` из уже готовых компонентов.
- **Готово, когда:** главная выглядит готовой, кроме реальных фото и цифр.

### Фаза 4 — Квиз (только интерфейс)
- 7 шагов + экран результата (варианты А и Б за переключателем), прогресс, «Назад», сохранение ответов. Кнопка ведёт на `/dyakuyemo`.
- **Готово, когда:** квиз проходится с телефона за 60 секунд.

## ПОСЛЕ ПОЛУЧЕНИЯ ФАКТОВ

### Фаза 5 — Остальные страницы и реальный контент
- Кейс, портфолио с фильтром, Меблі, Ремонт, Контакти, Дякуємо, Політика, 404. Заменить заглушки в `facts.ts`, фото в WebP, 15–25 кейсов.

### Фаза 6 — Заявки
- PHP-скрипт `api/lead.php` на хостинге: Telegram + Google Sheets (Apps Script) + email, UTM, поле-ловушка, ограничение частоты по IP. **Агенты:** `tdd-guide`, затем `security-reviewer`.
- **Готово, когда:** тестовая заявка с телефона приходит в Telegram ≤ 1 мин и пишется в таблицу.

### Фаза 7 — Аналитика и SEO
- GA4, GTM, Meta Pixel, Clarity, события из ТЗ; title/description, sitemap, robots, LocalBusiness, FAQ-разметка.

### Фаза 8 — Проверка качества
- **Агенты:** `e2e-runner` (Playwright 375 и 1280 px), `code-reviewer`; Lighthouse mobile.
- **Готово, когда:** Performance ≥ 90, Accessibility ≥ 90, SEO ≥ 95; e2e зелёные; критических замечаний нет.

### Фаза 9 — Запуск
- Хостинг adm.tools, деплой GitHub Actions по SFTP (доступы в GitHub Secrets), домен, HTTPS (бесплатный SSL), Search Console, ссылки с UTM в карточке Google и Instagram.
- **Готово, когда:** реальная заявка с боевого домена дошла в Telegram.
