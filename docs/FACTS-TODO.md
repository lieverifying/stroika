# Что нужно от владельца — список фактов для сайта

**Режим запуска (2026-10-21): нет факта — нет блока.** Всё, для чего ещё нет данных, на сайте скрыто: пустых плашек нет.
Когда приходит факт, разработчик вносит его в `src/content/facts.ts` и, если блок за флагом, включает флаг в `facts.flags`.
Боевая сборка не пропустит флаг, включённый без фактов.

Пример в колонке «Формат ответа» показывает только **вид** ответа. Это не наше предложение: пишите свои настоящие данные.
В скобках — служебное имя, по нему разработчик найдёт место.
